# 🎮 Tic Tac Toe Game

This project offers a modern twist on the classic Tic Tac Toe game. In addition to the traditional 3x3 grid, multiple board sizes are available, including 3x3, 4x4, and 5x5, which adds a new level of challenge and engagement. This variation caters to players of all skill levels, making the gameplay experience both fun and dynamic. 💡

## 🛠 Technologies Used:
| Technology   | Description |
|--------------|-------------|
| **HTML**     | Structure of the game. |
| **CSS**      | Styling and layout for an appealing visual experience. |
| **JavaScript** | Core game logic for handling user interactions and gameplay rules. |
| **jQuery**   | For dynamic updates and smooth interactivity. |
| **Bootstrap** | For responsive design to ensure compatibility across devices and screen sizes. |

## 💡 Key Features:
- **Multiple Board Sizes**: Choose from 3x3, 4x4, or 5x5 boards for a variety of difficulty levels.
- **Clean and Responsive Design**: Optimized layout for both desktop and mobile screens to ensure a seamless user experience.
- **Smooth Interactivity**: Real-time feedback with intuitive gameplay mechanics.
- **Mobile and Desktop Friendly**: Fully responsive and optimized for all screen sizes.
